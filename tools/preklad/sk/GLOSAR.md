# Česko-slovenský glosář pro překlad obsahu chem-uni.com

Závazný pro všechny překlady do slovenštiny. Když si nejste jistí termínem, který tu
není, zvolte termín používaný ve slovenských středoškolských učebnicích chemie
(spisovná slovenčina, ŠVP) a přidejte ho sem do tabulky „Doplněno při překladu“.

## Styl
- Spisovná slovenčina, žádné čechismy. Pozor na „falešné přátele“: ČJ *pozor* = SK *pozor*,
  ale ČJ *právě* = SK *práve*, ČJ *zkusit* = SK *skúsiť*, ČJ *zadání* = SK *zadanie*,
  ČJ *řešení* = SK *riešenie*, ČJ *dosadit* = SK *dosadiť*, ČJ *vztah* = SK *vzťah*,
  ČJ *výsledek* = SK *výsledok*, ČJ *zlomek* = SK *zlomok*, ČJ *závorka* = SK *zátvorka*,
  ČJ *chyba* = SK *chyba*, ČJ *krok* = SK *krok*, ČJ *nápověda* = SK *nápoveda*,
  ČJ *klepnout* = SK *ťuknúť / kliknúť*, ČJ *tahák* = SK *ťahák*, ČJ *rychlokurz* = SK *rýchlokurz*.
- Oslovení vykáním (2. osoba množného čísla), stejně jako v originále.
- Tón i délka jako originál. Nic nevynechávat, nic nepřidávat, nevysvětlovat navíc.
- Typografie: uvozovky „…“, pomlčka —, desetinná čárka (0,5), mezera mezi číslem a jednotkou,
  nezlomitelná mezera `&nbsp;` po jednopísmenných předložkách a spojkách (a, i, k, o, s, u, v, z)
  tam, kde ji má originál.
- Vzorce, značky prvků, jednotky, čísla, rovnice a proměnné se NEPŘEKLÁDAJÍ a nemění.
- Odkazy na české zkoušky (maturita, přijímačky) se jen přeloží: *maturita*, *prijímačky*.
- Název knihy (Klikorka… *Obecná a anorganická chemie*) a vlastní jména zůstávají česky.
