VIII · výpočty v praxi

Řešené příklady

Tři úlohy, které na sebe navazují: nejdřív zjistíme přesnou koncentraci NaOH, s ní stanovíme ocet, a nakonec standardizujeme HCl. Kroky si rozbalujte postupně a vždy nejdřív zkuste odhadnout, co přijde.

Příklad 1: standardizace NaOH na KHP

Úloha: k přesnému stanovení koncentrace připraveného roztoku NaOH se navážilo 0,7532 g čistého hydrogenftalanu draselného (KHP, M = 204,22 g/mol). KHP se rozpustil ve vodě, přidal se fenolftalein a titrovalo se roztokem NaOH do trvale růžového zbarvení. Spotřeba NaOH byla 35,85 ml. Vypočítejte přesnou koncentraci NaOH.

KHP navážka
0,7532 g→ n = m/M KHP
? mol→ 1 : 1 NaOH
? mol→ c = n/V NaOH spotřeba
35,85 ml standard navážený přímo do baňky → žádný alikvot
Krok 1: reakce a stechiometrie

KHP (HC₈H₄O₄⁻) je jednosytná kyselina: HC₈H₄O₄⁻ + OH⁻ → C₈H₄O₄²⁻ + H₂O

Poměr: n(KHP) : n(NaOH) = 1 : 1

Krok 2: látkové množství KHP

n = m/M = 0,7532 g / 204,22 g/mol = 3,688·10⁻³ mol

Krok 3: látkové množství NaOH

Z poměru 1 : 1: n(NaOH) = n(KHP) = 3,688·10⁻³ mol

Krok 4: koncentrace NaOH

c = n/V = 3,688·10⁻³ mol / 0,03585 l = 0,10288 mol/l

Koncentrace roztoku NaOH je přibližně 0,1029 mol/l.

Příklad 2: stanovení kyseliny octové v octu

Úloha: 10,00 ml kuchyňského octu se pipetou přeneslo do 100 ml odměrné baňky a doplnilo destilovanou vodou po značku (zředění 1 : 10). Z tohoto roztoku se odebralo 20,00 ml do titrační baňky, přidaly se 2 kapky fenolftaleinu a titrovalo se roztokem NaOH o koncentraci 0,1029 mol/l (z příkladu 1). Spotřeba NaOH byla 13,55 ml. Vypočítejte hmotnostní procento kyseliny octové (CH₃COOH, M = 60,05 g/mol) v octu o hustotě 1,01 g/ml.

ocet
10,00 ml→ zředit odměrná baňka
100 ml→ odebrat alikvot
20,00 ml→ titrovat NaOH 0,1029 mol/l
13,55 ml titrujeme pětinu baňky → výsledek × 5
Krok 1: reakce a stechiometrie

Kyselina octová je jednosytná slabá kyselina: CH₃COOH + NaOH → CH₃COONa + H₂O

Poměr: n(CH₃COOH) : n(NaOH) = 1 : 1

Krok 2: látkové množství NaOH

n = c·V = 0,1029 mol/l · 0,01355 l = 1,394·10⁻³ mol

Krok 3: CH₃COOH v alikvotu (20 ml zředěného roztoku)

Z poměru 1 : 1: n(CH₃COOH) ve 20 ml = 1,394·10⁻³ mol

Krok 4: CH₃COOH ve 100 ml zředěného roztoku

Faktor přepočtu 100 ml / 20 ml = 5: n = 1,394·10⁻³ · 5 = 6,972·10⁻³ mol. Tolik kyseliny pochází z původních 10,00 ml octu.

Krok 5: hmotnost CH₃COOH v 10,00 ml octu

m = n·M = 6,972·10⁻³ mol · 60,05 g/mol = 0,4186 g

Krok 6: hmotnostní procento CH₃COOH

m(octu) = 10,00 ml · 1,01 g/ml = 10,10 g
w = 0,4186 / 10,10 · 100 % = 4,14 %

Obsah kyseliny octové v kuchyňském octu je přibližně 4,1 % hmotnostních.

Příklad 3: standardizace HCl na Na₂CO₃

Úloha: k přesnému stanovení koncentrace připraveného roztoku HCl se navážilo 0,1325 g bezvodého Na₂CO₃ (M = 105,99 g/mol). Látka se rozpustila ve vodě, přidala se methyloranž a titrovalo se roztokem HCl do barevného přechodu indikátoru (ze žluté do cibulově oranžové). Spotřeba HCl byla 23,65 ml. Vypočítejte přesnou koncentraci HCl.

Na₂CO₃ navážka
0,1325 g→ n = m/M Na₂CO₃
? mol→ 1 : 2 (!) HCl
? mol→ c = n/V HCl spotřeba
23,65 ml pozor: 1 Na₂CO₃ spotřebuje 2 HCl → n(HCl) = 2 · n(Na₂CO₃)
Krok 1: reakce a stechiometrie

Uhličitan sodný reaguje s HCl ve dvou stupních, ale s methyloranží titrujeme až do druhého stupně: Na₂CO₃ + 2HCl → 2NaCl + H₂O + CO₂

Poměr: n(Na₂CO₃) : n(HCl) = 1 : 2

Krok 2: látkové množství Na₂CO₃

n = 0,1325 g / 105,99 g/mol = 1,250·10⁻³ mol

Krok 3: látkové množství HCl

n(HCl) = 2 · 1,250·10⁻³ = 2,500·10⁻³ mol

Krok 4: koncentrace HCl

c = 2,500·10⁻³ mol / 0,02365 l = 0,10572 mol/l

Koncentrace roztoku HCl je přibližně 0,1057 mol/l.
IX · závěrečné shrnutí

Shrnutí

Acidobazické titrace jsou základní analytická technika ke stanovení koncentrace kyselin a zásad. Klíčem k úspěchu je odměrný roztok silné kyseliny nebo zásady o známé koncentraci (často určené standardizací), správný výběr indikátoru podle pH v bodě ekvivalence (to závisí na síle titrované kyseliny nebo zásady) a omezení chyb, hlavně při práci se zásadami kvůli CO₂.
